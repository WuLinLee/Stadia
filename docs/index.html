Install and verify

刷入与测试

01 · 硬件准备

使用带原生 USB OTG 的 ESP32-S3 开发板和可传输数据的 USB 线。
将 Stadia 手柄切换到 Bluetooth 模式，并让它进入可配对状态。
先连接电脑刷写，完成后设备会重新枚举为 Xbox 360 兼容手柄。

02 · A/B 对照

先使用 Reference。依次测试 0、1、8、16、32、64、128、192、224、255，然后对照 Gentle 与 Punch。

比较时固定游戏、场景、电量、握持方式和马达通道。注意记录游戏输出和手柄外壳加速度，不要仅凭固件编译成功就判定震感复刻成功。

03 · 获取源码与构建

每个 push / PR 会运行三套强度公式测试，并通过 GitHub Actions 编译三个 ESP32-S3 完整镜像。

打开 Actions 下载构建产物 →

Transparency

我们明确知道什么

确定事实

Xbox 360 风格输出报告提供 8 位强/弱马达值；Stadia HID 输出端使用两个 16 位小端数值。Reference 使用 x × 257 将 0–255 均匀扩展到 0–65535。

可验证假设

非线性 gamma 曲线可能在低强度下更容易感知，但会改写游戏请求的幅值关系；不同马达的物理响应也可能不同。

仍未知

Google Stadia 云端历史震动数据、内部强度算法和原版马达校准曲线尚未由公开源码证实。需要原始抓包或物理测量才能做严谨复刻。
